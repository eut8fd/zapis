# Zapis — демо SaaS онлайн-записи в Telegram

Полноценная интерактивная демо-версия продукта: Telegram Mini App + бот.
Открывается **одной кнопкой в Telegram** — ссылки никуда вводить не нужно.

---

## Быстрый старт

```bash
powershell -ExecutionPolicy Bypass -File scripts/start-demo.ps1
```

Скрипт делает всё сам:

1. поднимает локальный сервер со статикой Mini App;
2. открывает https-туннель Cloudflare (без аккаунта, бесплатно);
3. записывает полученный адрес в `.env` и прописывает его боту;
4. включает **кнопку «Открыть» рядом с полем ввода** и запускает бота.

Дальше в Telegram: **@Demotelaibot → /start → кнопка «Открыть приложение»**.

Остановка — `Ctrl+C` (или `scripts/stop-demo.ps1`).

> Адрес туннеля живёт, пока запущен скрипт. При каждом запуске он новый —
> бот перенастраивается автоматически. Для постоянного адреса залейте папку
> `webapp/` на любой https-хостинг и запустите
> `scripts/start-demo.ps1 -Url https://ваш-домен`.

Только браузер, без Telegram: `scripts/start-demo.ps1 -NoTunnel` → http://localhost:8080

## Что внутри

| | |
|---|---|
| `webapp/` | Mini App: чистые ES-модули, без сборки и зависимостей |
| `bot/bot.py` | Бот на стандартной библиотеке Python (long polling) |
| `server/serve.py` | Статический сервер для `webapp/` |
| `scripts/` | Запуск демо, остановка, настройка доступа админа |
| `.env` | Токен бота, адрес приложения, ключи админки |

Данные демо живут в `localStorage` устройства: всё, что вы сделали, сохраняется,
а «Сбросить демо» возвращает исходное состояние.

## Роли и сценарии

| Роль | Что показывает |
|---|---|
| **Клиент** | Страница салона → услуга → мастер → дата → время → анимированный success → «Мои записи», перенос и отмена |
| **Сотрудник** | Свой день, следующий клиент, AI-шпаргалка перед визитом, свой календарь и клиенты |
| **Владелец** | Дашборд, календарь (день/неделя), CRM, услуги, команда, графики, финансы, аналитика, рассылки, подписка, AI |
| **Super Admin** | Компании, подписки, MRR, проблемные подписки, карточка компании с Danger Zone |

Переключение ролей и компаний — кнопка-щит слева внизу (**демо-панель**).
Там же машина времени (`+2 часа`, `+1 день`, `+7 дней`), тестовое напоминание,
онбординг с нуля и сброс демо.

### Связанность данных

Запись, созданная клиентом, сразу видна мастеру и владельцу, занимает слот в
календаре, попадает в CRM, статистику и финансы. Отмена возвращает слот и
пересчитывает показатели. AI-инсайты считаются по этим же данным, а не по заглушкам.

## AI-помощник

Два режима с одинаковым интерфейсом:

* **DEMO** (по умолчанию) — работает без ключа, все цифры и тексты считаются по демо-базе;
* **LIVE** — «Настройки → AI-помощник», вставьте API-ключ; чат и тексты идут в модель.

Разделы: итоги недели с конкретными действиями, заполнение свободных окон
(с симуляцией рассылки), возврат клиентов, генератор сторис, чат по данным
бизнеса и голосовая заметка о клиенте с разбором по категориям.

## Доступ к Super Admin

Панель закрыта двумя независимыми ключами:

1. **Telegram ID** из белого списка — панель открывается сразу;
2. **секретный код** — вводится вручную или приходит от бота в ссылке.

В коде приложения хранится только **SHA-256** секрета — самого кода в исходниках нет.

```bash
# узнать свой Telegram ID: напишите боту /admin — он вернёт его в ответе
powershell -File scripts/set-admin-code.ps1 -TelegramId 123456789
powershell -File scripts/set-admin-code.ps1 -Code "новый-секрет"
```

Скрипт обновляет `webapp/js/config.js` (хэш и список ID) и `.env` (для бота).
После изменения перезапустите демо.

Как войти:

* `/admin` в боте — работает только для ID из белого списка;
* демо-панель → «Super Admin» → ввод кода;
* скрытый вход: «Настройки» → 5 быстрых нажатий по строке с версией.

Выход и закрытие доступа на устройстве: «Система → Выйти из Super Admin».

> Честное предупреждение: приложение полностью клиентское, поэтому это защита
> «чтобы не зашёл случайный человек», а не серверная авторизация. Когда появится
> бэкенд, ту же проверку нужно перенести на сервер — валидировать `initData`
> Telegram и роль по Telegram ID. Точки проверки уже вынесены в `webapp/js/config.js`.

## Бот: как он выглядит для пользователя

При каждом запуске бот сам приводит себя в «продуктовый» вид:

* **имя и описания** — короткое (в профиле) и полное (экран «Что умеет этот бот»
  до первого запуска);
* **кнопка «Открыть»** рядом с полем ввода — запускает приложение в один тап;
* **команды**: `/start` — главное меню, `/app` — открыть приложение, `/help` — помощь.

### Меню разное для клиента и для бизнеса

Бот запоминает, кто перед ним, и показывает только то, что этому человеку нужно.
Роль хранится в `bot/users.json`, кнопка рядом с полем ввода тоже меняется.

**Клиент** — пришёл по ссылке салона `t.me/<бот>?start=c1`. Видит меню салона,
без единого слова про SaaS, тарифы и возможности:

```
Beauty Studio Lumière
★ 4.9 · 214 отзывов · Алматы
ул. Достык 132, 2 этаж

[      📅 Записаться      ]
[ Мои записи ] [ Услуги и цены ]
[    Адрес и контакты     ]
[    Это не мой салон     ]
```

Кнопка меню у него называется **«Записаться»** и открывает выбор услуги сразу.

**Бизнес** — выбрал «У меня бизнес». Видит меню своей компании:

```
Beauty Studio Lumière
Салон красоты · Алматы · тариф PRO

[   💼 Открыть кабинет   ]
[ Календарь ] [ Клиенты ]
[  Ссылка для клиентов   ]
[ Подписка ] [ Поддержка ]
[   Сменить компанию     ]
```

Кнопка меню — **«Кабинет»**. «Ссылка для клиентов» выдаёт готовую ссылку и
кнопку «Отправить» — её можно сразу кинуть в сторис или профиль.

**Новый человек без ссылки** видит короткую витрину с выбором «Я клиент /
У меня бизнес» и разделами «Возможности» и «Тарифы».

Все разделы открываются прямо в том же сообщении и возвращаются кнопкой «‹ Назад» —
чат не засоряется.

Публичные данные салонов для меню лежат в `bot/companies.json` (в реальном
продукте их отдавал бы бэкенд).

`.env`:

```
BOT_TOKEN=...            # токен от @BotFather
WEBAPP_URL=              # заполняется автоматически при запуске туннеля
BRAND_NAME=Zapis         # как продукт называется в текстах бота
BOT_NAME=Zapis — онлайн-запись   # имя бота; пусто = не менять
SUPPORT_USERNAME=        # username поддержки без @; пусто = кнопка скрыта
ADMIN_TG_IDS=            # Telegram ID супер-админов через запятую
ADMIN_CODE=              # секретный код (его хэш — в webapp/js/config.js)
```

Скрытые команды (в списке не показываются): `/app`, `/owner`, `/staff` —
быстрый вход для показа, и `/admin` — панель для белого списка.

**Ссылки для демонстрации** (бот печатает их при старте):

| Ссылка | Что откроется |
|---|---|
| `t.me/<бот>?start=c1` | меню клиента Beauty Studio Lumière |
| `t.me/<бот>?start=c2` | меню клиента BLADE Barbershop |
| `t.me/<бот>?start=c3` | меню клиента SPA Ritual |
| `t.me/<бот>?start=biz` | меню бизнеса |

Внутри приложения тот же параметр открывает конкретный экран:
`c1_book` — сразу выбор услуги, `c1_my` — мои записи, `owner_cal` — календарь,
`owner_clients` — база клиентов, `owner_sub` — подписка.

> Токен бота засветился в переписке — перед показом реальным людям сделайте
> `/revoke` у @BotFather и подставьте новый в `.env`.
