## Известные проблемы и ограничения

### Требуют внимания

- **Данные в браузере.** Клиент и владелец на разных устройствах видят
  разные базы. Связку ролей показывать только на одном устройстве
  через демо-панель. Лечится только бэкендом.
- **Демо-панель доступна всем ролям кроме клиента.** Мастер и владелец
  видят кнопку-щит. Для показа это удобно, для продакшена — убрать.
- **`DEMO_OPEN_ADMIN = true`** в `webapp/js/config.js`: панель Super Admin
  открыта свободно. Перед продакшеном поставить `false`.
- **Токен бота засветился** в переписке — сменить через @BotFather.
- **Часовой пояс один.** Все даты наивные, без `tz`. Для мультигорода
  нужна зона компании.

### Мелочи, не влияющие на демонстрацию

- Уведомления (`o.notifications`) — просто список ближайших записей,
  реальных уведомлений нет.
- Рейтинг мастера хранится, но нигде не пересчитывается по отзывам.
- Поиск по клиентам ограничен 60 записями в выдаче.
- Пагинации нет нигде — на демо-объёмах не мешает.
- Категория `other` появляется только после удаления пользовательской
  категории; отдельно её выбрать нельзя.
